아이폰 · 아이패드 · 안드로이드

설치 없이 웹에서 바로 씁니다. 홈 화면에 넣으면 앱처럼 전체 화면으로 열립니다.

웹에서 열기
  1. 아이폰·아이패드 — 사파리로 열고 공유 → 홈 화면에 추가 (크롬이 아니라 사파리여야 합니다)
  2. 안드로이드 — 크롬 메뉴 → 앱 설치

무엇을 할 수 있나

  1. 넘겨 읽기 — 가장자리 탭·좌우 밀기·키보드
  2. 한 장에 든 두 쪽 나눠 보기 — 스캔한 책을 폰에서도 읽을 만하게
  3. 여백 자르기 — 같은 화면에서 글자가 훨씬 커집니다
  4. 한국어 전체 검색 — 띄어쓰기가 달라도 찾습니다
  5. 칠하기·북마크·내보내기, 쪽을 JPG 로 (5장 넘으면 zip)
  6. 다크 리딩 — 밝기만 뒤집고 사진은 원래 색을 지킵니다
  7. 스캔본을 글자로 — 직접 지정한 서버로 OCR (선택)

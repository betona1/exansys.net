## 📝 출시 노트 (Play Console → 프로덕션 → 새 버전 → 출시 노트, ko-KR)

### 1.0.0 (versionCode 1) — 첫 출시
```
ExaPDF 첫 출시입니다.

• PDF를 책처럼 한 쪽씩 넘겨 읽기 — 읽던 자리 자동 저장
• 한국어 전체 검색 — 띄어쓰기가 달라도, 서재 전체에서도
• 여백 잘라내기 — 본문만 크게
• 다크·세피아 읽기, 밝기·대비 조절
• 5색 하이라이트, 북마크, 쪽 이미지 저장
• 회원가입 없이 바로 사용, 광고·추적 없음

원본 PDF 파일은 절대 수정하지 않습니다.
```

## ⬜ 대표님이 할 일 (Play Console)
1. play.google.com/console → **앱 만들기** (이름: ExaPDF — PDF를 책처럼, 무료, 앱)
2. **프로덕션 → 새 버전** → `app-release.aab` 업로드, 위 출시 노트 붙여넣기
3. 스토어 등록정보: `앱정보.md` 2~4절 붙여넣기 + `icon_512.png`·`feature_graphic.png`·스크린샷 업로드
4. **데이터 보안** 설문: `앱정보.md` 6절 답변대로 (수집 없음, 광고·분석 SDK 없음)
5. 콘텐츠 등급 설문(유틸리티/생산성, 전체이용가), 타겟 고객층
6. 개인정보처리방침 URL 입력
7. 검토 제출

> ⚠️ 신규 개인 개발자 계정은 프로덕션 전에 **비공개 테스트(테스터 12명, 14일)** 요건이
> 있을 수 있음 — 콘솔 안내에 따라 비공개 테스트 트랙부터 시작. (VibeQuest 때와 동일)

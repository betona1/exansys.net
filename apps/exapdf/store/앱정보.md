## 4. 전체 설명 (4000자 이내)
```
📖 PDF, 문서가 아니라 책으로 읽으세요

논문·전공서·스캔본을 폰으로 읽다 보면 늘 같은 불편이 반복됩니다.
글자는 작고, 여백은 넓고, 검색은 안 되고, 읽던 자리는 사라지고.
ExaPDF는 그 불편만 골라서 없앤 PDF 리더입니다.

⚡ 책처럼 넘겨 읽기
· 탭 한 번, 휠 한 칸으로 한 쪽씩 또렷하게
· 읽던 자리 자동 저장 — 열면 바로 그 쪽
· 두 쪽 펼침(태블릿), 한 쪽 나눠 보기(세로 스캔본)

✂️ 여백 크롭
· 넓은 여백을 자동으로 찾아 잘라내고 본문만 크게
· 스캔본에서 특히 강력합니다

🔍 한국어가 되는 전체 검색
· 책 안에서, 서재 전체에서 문장을 찾습니다
· 띄어쓰기가 달라도, 자모가 분리돼 있어도 찾아냅니다

🖍️ 하이라이트와 북마크
· 5색 형광펜, 북마크, 쪽 이미지로 잘라 저장
· 원본 PDF 파일은 절대 건드리지 않습니다

🌙 눈이 편한 읽기
· 다크 읽기(휘도 반전), 세피아, 밝기 조절
· 이미지 영역은 원본 색을 유지합니다

🔒 내 자료는 내 기기에만
· 회원가입 없이 바로 사용
· 사용 기록·분석 도구·광고 없음
· 책·주석·검색 색인 전부 기기 안에만 저장

📷 스캔본 OCR (선택)
· 사진으로 된 스캔본도 글자로 바꿔 검색·복사
· 계정을 연결한 경우에만 동작하는 선택 기능입니다

작고 단단한 도구를 만드는 EXANSYS 의 두 번째 앱입니다.
```

# 북뷰 사용 설명서

PDF 로 저장한 책을 **책처럼** 읽는 앱입니다.
앱 안에서도 볼 수 있습니다 — 서재 오른쪽 위 **?** 버튼.

---

## 처음 열면

책을 처음 열 때 조작 안내가 한 번 뜹니다.
화면을 세 칸으로 나눠 **실제 그 자리에** 표시하니, 어디를 눌러야 하는지
글로 읽지 않아도 됩니다.

- **알겠습니다** — 이번만 닫습니다
- **앞으로 안내 보지 않기** — 다시 뜨지 않습니다

다시 보고 싶으면 **? → 안내 표시**를 켜면 됩니다.

---

## 1. 책 넘기기

| 어떻게 | 무엇이 |
|---|---|
| 화면 좌·우 **가장자리를 누르기** | 이전 / 다음 쪽. 가장 빠릅니다 |
| 좌우로 **밀기** | 넘기던 느낌 그대로 |
| 스페이스 · 엔터 · → · ↓ · PageDown | 다음 쪽 |
| ← · ↑ · PageUp | 이전 쪽 |
| Home / End | 첫 쪽 / 마지막 쪽 |
| 마우스 휠 | 쪽 안에서 아래로 내려가다가, 끝에 닿으면 넘어갑니다 |

가운데를 누르면 위아래 메뉴가 숨었다 나옵니다. 글에 집중할 때 쓰세요.

---

## 2. 크게 보기·옮기기

| 어떻게 | 무엇이 |
|---|---|
| **두 번 두드리기** | 확대 ↔ 원래대로 |
| 손가락 두 개로 벌리기 | 원하는 만큼 확대 |
| **Ctrl + 휠** | 컴퓨터에서 확대·축소 |
| **끌기** | 확대했거나 화면 밖으로 넘칠 때 위아래·좌우로 옮깁니다 |
| 🔒 자물쇠 | 지금 크기와 좌우 위치를 **고정**합니다. 쪽을 넘겨도 그대로 |

> 자물쇠는 스캔본에서 특히 쓸모가 있습니다. 쪽마다 스캔 위치가 조금씩
> 달라도 한 번 맞춰 두면 계속 같은 자리로 보입니다.

축소하면 그림이 저절로 화면 안으로 돌아옵니다 — 한쪽이 잘려 나가 사라지는
일은 없습니다.

---

## 3. 보기 맞추기

- **폭 맞춤** — 좌우를 화면에 꽉. 글자가 가장 큽니다 (기본)
- **화면 맞춤** — 쪽 전체가 한눈에
- **세로 맞춤** — 위아래를 화면에
- **반 가르기** — 한 장에 두 쪽이 스캔된 책을 한 쪽씩
- **여백 자르기** — 스캔 여백을 잘라 내면 같은 화면에서 글자가 훨씬 커집니다
- **다크 리딩** — 밤에 눈이 덜 부십니다. 밝기만 뒤집고 **사진은 원래 색을 지킵니다**

가로로 들면 책이 훨씬 잘 보입니다. 위아래 시스템 바도 숨습니다.

---

## 4. 표시하고 남기기

- **칠하기** — 색을 고르고 끌면 그 자리가 칠해집니다 (색 다섯 가지)
- **칠한 것 고치기·지우기** — 칠한 곳을 누르면 테두리가 생기고 옆에 막대가
  뜹니다. 색을 바꾸거나, 메모를 달거나, 휴지통으로 지웁니다.
  컴퓨터에서는 **Del** 키로도 지웁니다. 지운 직후 **되돌리기**가 뜹니다
- **북마크** — 지금 쪽을 접어 둡니다
- **내보내기** — 칠한 곳과 북마크를 글 파일로 꺼냅니다
- **쪽 이미지** — 쪽을 JPG 로. **다섯 장이 넘으면 zip 하나**로 묶습니다

> 원본 PDF 는 절대 고치지 않습니다. 칠한 것과 북마크는 앱 안에만 담깁니다.

---

## 5. 찾기

- 돋보기를 누르면 **이 책 안에서** 찾습니다
- 서재 화면의 돋보기는 **모든 책에서** 찾습니다
- 한글은 띄어쓰기가 달라도 찾습니다. 한 글자만 넣어도 됩니다

### 스캔본은 왜 안 찾아지나

사진으로 찍어 만든 책에는 글자가 들어 있지 않습니다. 사람 눈에는 글자로
보이지만 앱에는 그림 한 장입니다. 그래서 찾기도 복사도 되지 않습니다.

돋보기를 누르면 **글자로 바꾸기**를 권해 드립니다 (다음 절).

---

## 6. 스캔본을 글자로 바꾸기 (OCR)

서버가 쪽 그림을 읽어 글자로 옮겨 적습니다. 끝나면 그때부터 **찾기와
복사가 됩니다.**

### 준비

글자를 읽어 줄 서버가 필요합니다. [Ollama](https://ollama.com) 를 올리고
비전 모델을 받아 두면 됩니다.

```
ollama pull qwen2.5vl:7b
```

밖에서도 쓰려면 서버가 다른 기기의 요청을 받도록 열어 둡니다.

```
OLLAMA_HOST=0.0.0.0
```

### 하는 법

1. 스캔본을 열고 **돋보기**를 누릅니다
2. 서버 주소를 넣습니다 — `192.168.219.88` 처럼 주소만 적어도 됩니다
   (포트를 안 적으면 11434 로 붙입니다)
3. **연결 확인**을 눌러 실제로 닿는지 봅니다
4. **시작**

### 알아 둘 것

- 쪽마다 **30초 안팎**. 책 한 권이면 한두 시간입니다
- 화면을 덮지 않습니다. 바꾸는 동안에도 책을 읽을 수 있습니다
- **한 쪽씩 저장됩니다.** 중간에 멈추거나 앱이 꺼져도 잃지 않고,
  다음에 남은 쪽부터 이어서 합니다
- 한 장에 두 쪽인 책은 **반 가르기를 켜 두면** 정확도가 올라갑니다.
  펼침을 통째로 보내면 몇 줄만 읽고 멈춥니다

### 웹에서는

브라우저 보안 때문에 제약이 있습니다.

- `https://` 페이지에서는 **`https://` 서버 주소**여야 합니다
- 서버가 브라우저 요청을 받도록 `OLLAMA_ORIGINS` 를 열어야 합니다

안드로이드 앱과 컴퓨터 앱에는 이 제약이 없습니다.

## 자주 묻는 것

**책이 잘려 보입니다**
폭 맞춤으로 바꾸거나, 반 가르기를 켜 보세요. 한 장에 두 쪽인 스캔본일
가능성이 높습니다. 그래도 한쪽이 안 보이면 손가락으로 끌면 됩니다.

**나갔다 오면 처음으로 돌아갑니다**
그러지 않습니다. 보던 쪽으로 돌아갑니다. 그렇지 않다면 알려 주세요.

**서재에서 책을 빼면 파일도 지워지나요**
아닙니다. 원본 파일은 그대로 있습니다.

**칠한 것이 원본 PDF 에 들어가나요**
아닙니다. 앱 안에만 담깁니다. 내보내기를 하면 **사본**에 씁니다.

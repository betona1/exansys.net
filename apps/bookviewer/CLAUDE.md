# CLAUDE.md — BookViewer (북뷰) 프로젝트 가이드

이 폴더(`apps/bookviewer/`)에서 작업할 때 따르는 규칙. **모든 대화·커밋은 한국어.**
상세 기능 명세는 `TECHSPEC.md`를 따른다.

**"PDF로 저장한 책을 진짜 책처럼 넘겨 읽고, 찾고 싶은 문장을 바로 검색하고, 중요한 부분은 캡처하거나 글자로 복사해 두는 생산성 리더."**

## 4. 핵심 기능 (사용자 요구)

1. **책처럼 보기** — 페이지 넘김, 좌우 펼침(두 쪽 보기), 진행률
2. **검색** — 문서 전체 텍스트 검색, 결과로 바로 이동
3. **캡처** — 화면의 원하는 영역을 잘라 이미지로 저장·공유
4. **글자 복사** — 본문 텍스트를 선택해 클립보드로 복사

## 5. 지켜야 할 원칙

- **남의 파일을 함부로 다루지 않는다.** 사용자가 고른 PDF만 열고, 원본을 수정하거나 몰래 복사하지 않는다
- **네트워크 없이 동작한다.** 읽기·검색·캡처는 전부 기기 안에서 끝난다
- **읽는 것을 방해하지 않는다.** 전면 광고·강제 팝업·다크 패턴 금지
- 권한은 실제로 쓰는 것만 요청한다 (파일 선택은 시스템 피커로 처리해 저장소 전체 권한을 피한다)

## 6. 폴더 구조

| 경로 | 내용 |
|---|---|
| `app/` | Flutter 앱 소스 |
| `data/` | 샘플 PDF·테스트 문서 등 개발용 자료 |
| `design/` | 아이콘 산출물 (`icon.png` 등). 원본은 `scripts/gen_icon.py` 로 다시 만든다 |
| `scripts/` | 자산 생성 스크립트 |
| `docs/` | 기획·조사 문서 |
| `store/` | Play 스토어 제출 자료 (아이콘·피처그래픽·스크린샷·문안). AAB/APK는 커밋하지 않는다 |

## 7. 작업 순서 (현재 위치: 2단계 진행 중)

- 0. 폴더·명세 — 완료
- 1. 기술 검증 — PDF 엔진으로 텍스트 추출·검색·선택이 실제로 되는지 확인 — **완료 (8/8)**
- **2. MVP — 열기 · 넘겨 읽기 · 검색 · 복사 · 캡처** ← 지금 여기
- 3. 다듬기 — 최근 읽은 책, 책갈피, 두 쪽 보기, 다크 리딩
- 4. 출시 — 스토어 자료, 개인정보처리방침(`exansys.net/apps/bookviewer/privacy`)

각 단계는 사용자 확인 후 다음으로 넘어간다.

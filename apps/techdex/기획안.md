# TechDex 기획안 (현황 + 로드맵)

> IT·AI·바이브코딩 용어를 **게임으로 익히는 학습 서비스**
> 작성 기준: EXANSYS · 문서 버전 v1 (현재 구현 반영)

---

## 1. 개요 (한 줄 요약)

**"용어를 몰라서 못 시작하는 비기너를, 퀴즈·십자풀이 게임으로 IT/AI 용어에 익숙해지게 만든다."**

- **브랜드/도메인**: TechDex — `techdex.exansys.net` (+ `exansys.net/techdex`)
- **타깃**: 코딩 입문자, 바이브코딩 시작자, AI 도구를 막 쓰기 시작한 비개발 직군
- **핵심 차별점**: EXANSYS 홈페이지 용어집과 **데이터·로그인을 공유**하는 연동형 학습 게임

---

## 2. 현재 구현 현황 ✅ (실제 동작 중)

### 플랫폼 (3형태, 한 백엔드 공유)
| 형태 | 상태 | 비고 |
|---|---|---|
| **웹** | ✅ 라이브 | `exansys.net/techdex` |
| **PWA** | ✅ 라이브 | `techdex.exansys.net` → "홈 화면에 추가" 설치형 |
| **네이티브 앱(Flutter)** | ✅ 동작(실기기 실행 확인) | Android/iOS. 스토어 출시는 별도 단계 |

### 게임 모드
- **🎯 스피드 퀴즈**: 정의(힌트)를 보고 4지선다로 용어 맞히기. 타이머·콤보·점수·복습.
  - **난이도 3단계**: 초급(쉬운 용어·18초) / 중급(12초) / 고급(어려운 용어·8초)
  - **사운드**: 정답·오답·째깍(매초)·막판 경고음 + 음소거
  - **움직이는 알람시계 타이머**(초침 회전 + 째깍 흔들림), 정답/오답 후 자동 진행
- **🧩 십자풀이(가로세로 퍼즐)**: 영문 용어를 교차 배치, 한글 뜻이 힌트. 정답 확인/보기·새 퍼즐.
- **📖 용어 도감**: 367개 용어 검색·분야 필터 열람.

### 커뮤니티
- **용어 추가 요청**: 검색에 없는 용어를 회원이 제안 → **관리자 검토·승인** 시 도감에 등록(collection=user).

### 데이터 (용어 DB)
- **총 367개** = 홈페이지 AI·앱 용어집 177 + 앱 개발 용어집 125 + 바이브코딩 사전 65 (중복 제거)
- 각 용어: 표시어·영문·뜻·분야(39종)·난이도(1~4)·필수 플래그·출처
- 외부 사전 정의문은 **복제하지 않고 한글로 재작성**(라이선스 안전), 출처 기록

## 3. 기술 아키텍처

```
                 ┌─────────────────────────────┐
                 │   Cloudflare Worker (Hono)   │  ← exansys.net 사이트와 동일 워커
                 │   /api/techdex/*             │
                 └───────┬───────────┬──────────┘
        D1 (SQLite)      │           │   KV(세션 공유) · R2
   techdex_terms         │           │
   techdex_suggestions   │           │
                 ┌───────┴───┐   ┌───┴────────┐
                 │ 웹 / PWA   │   │ Flutter 앱 │   → 같은 API 사용
                 │ React+Vite │   │ (http)     │
                 └───────────┘   └────────────┘
```

- **무료 Cloudflare 플랜** 범위 내(유료 기능 미사용). 홈페이지와 로그인·용어 **단일 출처** 공유.
- API: `stats · categories · terms · quiz · crossword · suggest · suggestions(관리)`.
- 배포: GitHub main push → Cloudflare Workers Builds 자동 배포. `techdex.exansys.net` 커스텀 도메인 연결됨.

# TechDex 리텐션 업그레이드 기획안 (선별판)

> 원본 리텐션 리서치(Duolingo·Trivia Crack·Wordle·Kahoot)에서 **우리 현실에 맞는 것만 취사선택**한 실행 기획.
> 원칙: "다 넣지 않는다. ROI × 구현가능성이 높은 것만, 단계적으로."

---

## 0. 전제 — 우리 상황에 맞춘 필터

원본 기획은 대형 팀·앱 기준이다. TechDex는 **Cloudflare 무료(D1·Workers) · 소규모 · 무광고 · 웹/PWA/Flutter** 다. 그래서 판단 기준을 이렇게 뒀다:

- **채택**: D1만으로 구현 가능 + 리텐션 효과 검증됨 + 학습 본질 강화
- **보류**: 실시간 인프라(WebSocket)·소셜 그래프·푸시 서버·광고 경제처럼 **무겁거나 우리 정체성과 안 맞는 것**

> **이미 완료된 "손맛"**: 제한시간(알람시계)·콤보·속도 점수·정답/오답 즉각 연출(사운드)·오답 복습 리스트. → 3.5 항목 상당수는 **이미 있음**. 여기에 스트릭·성장·데일리를 얹는다.

---

## 1. 핵심 목표

**기존 활성 사용자를 매일 다시 오게 하는 리텐션(CURR).** 신규 유입보다 유지가 성장의 지렛대.
- 1차 지표: **D1 / D7 유지율**, 평균 연속 스트릭
- 북극성: **CURR**

## 2. 채택 / 보류 결정표

| 장치 | 결정 | 이유 (우리 기준) |
|---|---|---|
| **스트릭 + 프리즈** | ✅ 채택(1순위) | 리텐션 최고 ROI, D1 필드 몇 개로 구현. 손실 회피 |
| **XP · 레벨** | ✅ 채택 | 모든 플레이를 성장으로 연결. D1 집계 |
| **첫날 성취/온보딩 배지** | ✅ 채택 | D1 유지율 33% vs 20%. 저비용·고효과 |
| **데일리 챌린지(오늘의 용어) + 결과 공유** | ✅ 채택 | Wordle식 '하루 1문제'+🟩 공유. 날짜 시드로 서버 고정, 바이럴 |
| **즉각 피드백·연출** | ✅ 대부분 완료 | 사운드·시계·콤보 있음 → 앱 **햅틱**·정답 이펙트만 보강 |
| **주간 리그(간소화)** | 🟡 2단계 | XP 기반 30명 코호트 주간 랭킹. D1 집계로 가능 |
| **오답 SRS 복습 + 약점 리포트** | 🟡 2단계 | 학습가치+재방문. 정답 기록 테이블 필요 |
| **스마트 알림** | 🟡 후속 | PWA 웹푸시는 비교적 가벼움 → 2단계 후 검토. 서버 스케줄 필요 |
| **실시간 PvP 대결** | ⛔ 보류 | WebSocket/Durable Objects 필요·무료범위 초과·매칭 복잡. (추후 '비동기 턴제'로 대체 검토) |
| **친구 스트릭·소셜 그래프** | ⛔ 보류 | 친구 관계 인프라 필요. 공유 카드로 바이럴만 먼저 |
| **하트/에너지 + 광고 경제** | ⛔ 미도입 | 학습앱 이탈 위험 + 우리는 **무광고** 정체성 유지 |
| **AI 실시간 적응형 난이도** | ⛔ 대체 | 복잡. **난이도 3단계(이미 있음) + SRS**로 갈음 |

## 3. 채택 항목 상세 (무엇을 만들까)

### 3-1. 스트릭 & 프리즈 — 습관의 뼈대 ★최우선
- 홈/퀴즈 상단에 **연속 학습일 🔥** 크게. "3일 연속! 오늘 5문제로 이어가세요"
- 하루라도 플레이(퀴즈 or 십자풀이 완료)하면 스트릭 +1
- **프리즈**: 하루 빠져도 안 깨지는 보호 1개 무료 지급(주 1회 충전). '족쇄' 안 되게 관대하게
- 10일·30일·100일 마일스톤 배지

### 3-2. XP · 레벨 — 진행의 감각
- 정답·연속정답·데일리 완료마다 XP. 레벨업 연출
- 레벨 명칭에 **용어 테마 정체성**: 프롬프트 유저 → 컨텍스트 러너 → 에이전트 마스터 …

### 3-3. 첫날 성취(온보딩)
- 가입 첫 세션에 **반드시 성취 1개**(첫 5문제·첫 정답·첫 스트릭) → 즉시 배지+XP

### 3-4. 데일리 챌린지 — 매일 올 이유
- **오늘의 용어**: 날짜 시드로 전원 동일한 문제 5개(서버 고정). 하루 1회 한정
- **결과 공유 카드**: "오늘의 AI 용어 3/3 🟩🟩🟩" (스포일러 없이) → SNS 공유로 유입

### 3-5. 즉각 피드백 (보강만)
- 이미: 사운드·알람시계·콤보·정답/오답 배너
- 추가: Flutter **햅틱**(정답 진동), 콤보 시 화면 이펙트, 오답 시 해설(이미 배너로 있음) 강화

### 3-6. (2단계) 주간 리그 — 가벼운 경쟁
- 매주 리셋, XP로 순위. **약 30명 코호트**로 묶어 '누구나 상위권 가능'
- 상위 승급/하위 강등(브론즈→실버→골드). 실력 무관, "이번 주 열심히"가 승급

### 3-7. (2단계) 오답 SRS 복습
- 틀린 용어를 망각곡선에 맞춰 재출제 → 학습성과 + 재방문 이유
- "자주 틀리는 용어 TOP 5" 약점 리포트

## 4. 데이터 모델 추가 (D1)

로그인(기존 OAuth) 사용자 기준으로 진행을 저장한다. **비로그인은 계속 플레이 가능하되, 진행 저장은 로그인 유도.**

```
techdex_user_stats(user_id PK, streak, best_streak, last_play_date,
                   freezes, xp, level, updated_at)
techdex_daily(date PK, term_slugs_json)          -- 오늘의 용어(전원 동일)
techdex_answers(user_id, term_slug, correct, wrong, last_seen, next_due)  -- SRS/약점
techdex_league(week, user_id, xp)                -- 주간 리그(집계)
techdex_badges(user_id, code, awarded_at)        -- 성취/마일스톤
```
- 모두 D1로 충분(무료 범위). 세션은 홈페이지 KV 공유.

## 5. 실행 로드맵

| 단계 | 테마 | 포함 | 겨냥 지표 |
|---|---|---|---|
| **1단계(MVP)** | 습관의 뼈대 | 스트릭+프리즈, XP·레벨, 첫날 성취/배지, 데일리 챌린지+공유, (햅틱 보강) | D1·D7, 평균 스트릭 |
| **2단계** | 가벼운 경쟁·학습 | 주간 리그, 오답 SRS·약점 리포트 | D7·D30, 세션 수 |
| **후속** | 재참여·바이럴 | PWA 웹푸시 알림, 비동기 대결(선택) | 복귀율, K값 |

> **1단계만으로도 D1·D7 개선을 기대**. 무겁고 불확실한 실시간 PvP·소셜은 뒤로.

## 6. KPI (기능이 아니라 '리텐션이 올랐는가')
- D1/D7/D30 유지율, 평균 스트릭, 데일리 챌린지 완료율, (2단계)리그 참여·승급률, 공유 수
- 코호트(가입일)로 추적

## 7. 지켜야 할 원칙
- **무광고 유지** (학습앱 이탈 1위가 광고 과다)
- **스트릭은 격려, 족쇄 금지** — 프리즈로 완충
- **학습 본질** — 오답 해설·SRS로 '진짜 용어 습득' 유지
- **단계 출시** — 한 번에 다 넣지 않기

---

## 8. 바로 시작 가능한 1단계 작업
1. `techdex_user_stats` 테이블 + 로그인 사용자 스트릭/ XP 적립 API
2. 퀴즈·십자풀이 완료 시 XP·스트릭 반영, 홈 상단 🔥스트릭 표시
3. 첫날 성취 배지 + 데일리 챌린지(오늘의 용어) + 결과 공유 카드
4. Flutter 햅틱 피드백

> 승인해주시면 **1단계 MVP부터** 실제 구현(웹·앱) 들어가겠습니다.
